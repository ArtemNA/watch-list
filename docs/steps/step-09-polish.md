# Step 09 — Поліш, бекап, PWA, деплой

**Передумови:** Steps 01–08 завершені та поревьювлені.

## Мета

Готова до щоденного користування апка: бекап даних, PWA для телефона,
чистка, деплой на Vercel.

## Завдання

1. **Експорт/імпорт JSON** (страховка незалежно від синку), сторінка «Налаштування»:
   - експорт: файл `watchlist-backup-YYYY-MM-DD.json` (всі айтеми + версія схеми),
   - імпорт: файл → превью (скільки нових / скільки збігаються по id) →
     злиття через ту саму `mergeItems` (конфлікти — той самий merge-діалог з Step 08),
   - сюди ж перенести перемикачі теми/мови (з шапки — залишити і там, і там).
2. **PWA**: `@angular/pwa` — manifest (назва WatchList, іконки, theme_color з токенів),
   service worker: app shell + постери (`image.tmdb.org`) кешувати
   `strategy: performance, maxAge 30d`; `/api/**` — НЕ кешувати в SW
   (щоб не заважати синку). Банер оновлення версії (SwUpdate → снекбар «Оновити»).
3. **Офлайн-UX**: індикатор офлайну в шапці; пошук в офлайні → empty state
   «Пошук недоступний офлайн»; бібліотека і редагування працюють повністю.
4. **Глобальні дефолти MatDialog**: завести `MAT_DIALOG_DEFAULT_OPTIONS`
   (ширина `min(480px, calc(100vw - 32px))`, autoFocus тощо) і прибрати
   інлайн-`width` з усіх `dialog.open(...)` (борг з step-04: Add Item,
   Delete Confirm; плюс ті, що додались у 05–08) — щоб «діалог на всю ширину
   на мобільному» (ARCHITECTURE §8) було одним правилом, а не копіпастою.
5. **Чистка**: сховати `/dev/ui` у проді (env-guard на роуті) — САМУ СТОРІНКУ
   НЕ ВИДАЛЯТИ, це постійний каталог дизайн-системи (CLAUDE.md); прибрати
   console.log, TODO-рев'ю, `npm audit` без high/critical (або задокументувати).
6. **Vacuum tombstones**: при старті видаляти локально айтеми з deletedAt > 90 днів,
   ТІЛЬКИ якщо є lastSyncAt новіший за deletedAt, або юзер ніколи не логінився.
7. **Деплой** (робить власник, підготуй усе): перевір `vercel.json`, напиши в
   README покроково: імпорт репо у Vercel, env vars (список), Atlas network
   access (0.0.0.0/0 для serverless), як перевірити прод.
8. Фінальний прогін чеклістів усіх step-файлів (регресія) — результат
   у `## Результат виконання` тут.

## Критерії приймання

- [ ] Апка встановлюється на телефон як PWA, бібліотека працює в airplane mode.
- [ ] Експорт → очистити IndexedDB → імпорт → все на місці.
- [ ] Lighthouse: PWA installable, performance ≥ 85 на бібліотеці.
- [ ] Прод на Vercel живий: пошук, додавання, синк між двома пристроями.
