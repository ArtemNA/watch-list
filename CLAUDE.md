# WatchList — інструкції для агентів

Персональна local-first апка «список фільмів/серіалів» (Angular + IndexedDB,
опційний синк у MongoDB через Vercel Functions). Власник — Angular-розробник Артем.

## Обов'язково перед будь-якою роботою

1. Прочитай `docs/PLAN.md` (статус кроків і правила процесу).
2. Прочитай `docs/ARCHITECTURE.md` (стек, структура, моделі, синк).
3. Якщо ти виконавець — працюй СТРОГО по одному файлу з `docs/steps/`,
   не залазь у наступні кроки.
4. Архітектурні рішення зафіксовані в `docs/DECISIONS.md` — не міняй їх мовчки.

## Після роботи (обов'язково)

- Онови чекбокси і журнал у `docs/PLAN.md`.
- Заповни `## Результат виконання` у своєму step-файлі: що зроблено,
  відхилення від плану, відомі проблеми.
- Переконайся, що `npm run build`, `npm run lint` і тести проходять.

## Ключові правила коду

- Angular: standalone-компоненти, signals; без NgModules.
- Стилі — ТІЛЬКИ через CSS-токени (`var(--...)`) з `web/src/design/tokens.scss`.
- Всі видимі рядки — через i18n (`uk.json`/`en.json`), одразу обома мовами.
- Доступ до IndexedDB — тільки через репозиторії в `core/data/`.
- API-ключі — тільки в env бекенда, ніколи у фронтенд-коді/бандлі.
- Секрети не комітяться (`.env.local` у .gitignore).
